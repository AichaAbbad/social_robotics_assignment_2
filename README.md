# Social Robotics Assignment 2

This repository contains the deliverables for **Assignment 2** of the *Social Robotics* course. The project involves designing and implementing interactive scenarios for the Pepper robot using **Choregraphe**, a visual programming environment developed by SoftBank Robotics.

## 📁 Repository Structure

- `assignment_soro_grp9_part_1/` – First part of the assignment, including Choregraphe project files and behavior trees for basic interactions.
- `assignment_soro_grp9_part_2/` – Second part of the assignment, featuring more advanced behaviors and interaction flows.
- `questionnaire/` – Includes user feedback forms and evaluation material used to assess the interaction experience.
- `report_social_robotics_assignment_2.pdf` – Detailed report describing the system design, implementation, user testing, and conclusions.

## 🧠 Tools & Technologies

- **Pepper robot**
- **Choregraphe** (SoftBank Robotics)
- Basic scripting in **Python** for robot behaviors

## 🚀 How to Use

1. Open **Choregraphe** on your machine.
2. Load the `.crg` project files from either `assignment_soro_grp9_part_1/` or `assignment_soro_grp9_part_2/`.
3. Connect to a real or simulated Pepper robot.
4. Run or test the behaviors directly within Choregraphe.

> 💡 Make sure Pepper is on the same network if using a real robot, and that required plugins or packages are installed within Choregraphe.
